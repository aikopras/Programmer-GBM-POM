CV values used by the Feedback decoder

The CVs below are used by the Feedback (GBM) decoder, with the OPENDECODER22GBM software. Default values can be restored with the DEFAULTS buttons, or for all CVs at once by writing 13 to CV8.

CVs used by all variants

CVNameAccessRangeDescription
1myAddrLR/WAccessory decoder address (for the relays), low order bits. See Feedback versus Accessory Decoder Addresses
3..6T_on_F1 .. T_on_F4RHold time of relay 1..4, in 20 ms steps
7versionRSoftware version
8VIDR/W13Vendor ID (13 = 0x0D: DIY decoder). Writing 13 resets all CVs to their default values, including the RS-Bus address (CV10 becomes 0)
9myAddrHR/WAccessory decoder address, high order bits. 128 (0x80) means: address not set
10myRSAddrR/W1..128RS-Bus address (the main address of the decoder). 0 means: address not set. After a new value is written, the decoder restarts
11..18DelayIn1 .. DelayIn8R/W0..255Delay (in 10 ms steps) before input 1..8 sends its OFF signal. If 0, the value of CV34 is used
19CmdStationR/W0..1Command station: 0 = standard (such as Roco), 1 = Lenz
20RSRetryR/W0..2Number of additional transmissions of each RS-Bus feedback message
21SkipUnEvenR/W0..1If 1: only decoder addresses 2, 4, 6 ... are used
23SearchR/W0..1If 1: the decoder LED blinks. Not stored; 0 after a restart
25RestartWWriting a value other than 0 restarts the decoder, so that new CV values take effect
26DccQualityR0..255Number of DCC checksum errors since the last restart
27DecTypeR/WDecoder Mode (Control tab): 48 = normal, 49 = reverser, 50 = relay, 52 = speed
28BiDiR0BiDi (RailCom) is not supported
29ConfigRAccessory decoder configuration (similar to CV29 of the NMRA)
30VID_2R13Second vendor ID, to recognise decoders by Aiko Pras
33Min_SamplesR/W1..8Number of consecutive samples (8 ms each) with the same outcome, before the result is considered stable
34Delay_offR/W0..255Delay (in 100 ms steps) before a previous occupancy is released. Used for the inputs whose CV11..18 is 0
35Threshold_onR/W10..255Above this value a previous OFF sample is regarded as ON
36Threshold_ofR/W5..255Below this value a previous ON sample is regarded as OFF. Should be lower than CV35

CVs used by the speed variant (Decoder Mode "speed")

CVNameAccessRangeDescription
37Speed1_OutR/W2..7Input of the first speed measurement track. 0 = none
38, 39Speed1_LL, Speed1_LHR/W100..5000Length in mm of the first speed measurement track (CV38 + 256 * CV39)
40Speed2_OutR/W2..7Input of the second speed measurement track. 0 = none
41, 42Speed2_LL, Speed2_LHR/W100..5000Length in mm of the second speed measurement track (CV41 + 256 * CV42)

CVs used by the reverser variant (Decoder Mode "reverser")

CVNameAccessRangeDescription
43..46FB_A .. FB_DR/W0..7Feedback bit that is set if track A..D is occupied
47..50FB_S1 .. FB_S4R/W0..7Feedback bit that is set if sensor 1..4 is active
51PolarizationR/W0..10 = J&K connected normal, 1 = J&K polarization changed

Note that the CVs 43–50 are shown as 1..8 on the Reverser tab.
